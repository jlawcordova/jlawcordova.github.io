# Pill

The compact accent call to action in the navigation bar.

## Use

- `.pill`: 44px tall, 18px horizontal padding, `radius-pill` corners, `pill` type (Silkscreen 13px), `color-on-accent` on `color-accent`.
- Use one per bar, for the main way to reach the owner.

## What you provide

- An `<a>` with a one-word label.
