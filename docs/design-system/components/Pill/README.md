# Pill

The compact accent call to action in the navigation bar.

## Use

- `.pill`: 44px tall, 18px horizontal padding, square corners, `border-thick`, `pill` type (Silkscreen 13px, uppercase), `color-on-accent` on `color-accent`. Despite the name, it's no longer rounded.
- Use one per bar, for the main way to reach the owner.

## What you provide

- An `<a>` with a one-word label.
