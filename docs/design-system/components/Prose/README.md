# Prose

The long-form reading column for posts and documents: headings, lists, links, blockquotes, tables, figures.

## Use

- `.post-body` inside a `reading-max` column, set in `post-body` (17px / 1.75). Blocks are spaced 1.1em apart, and headings get 1.6em above them.
- Links are `color-accent` and underlined with a 3px offset. Images get square corners and a `color-border` hairline. Figure captions are `caption` in `color-ink-muted`.
- Blockquotes are a frosted `color-surface` box with square corners. Use them for the question you want answered, not for decoration.
- Table headers are `label` (Silkscreen, uppercase). Rows are separated by `color-border`.

## What you provide

- Rendered Markdown. Structure it as the five questions: context, assumptions, risks, recommendation, next actions.
