# Footer

The one-line footer: the copyright on the left, and links elsewhere on the right, all in pixel type.

## Use

- `.site-footer`: `color-on-footer` on `color-footer`, `label`-sized Silkscreen (12px, 1px tracking), 22px vertical padding plus the gutter.
- Every link is at least 44 × 44px, even the one-letter X. On hover or focus it's underlined. Focus uses a `color-on-forest` outline over a `color-footer` halo.

## What you provide

- The year and up to four uppercase link labels.
